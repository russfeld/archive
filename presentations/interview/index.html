Polymorphism

noun: The ability to assume different forms or shapes


In programming, polymorphism allows an object to assume different forms and perform different operations based on its type.
An object can assume multiple types based on its class hierarchy (or inheritance).

Can we have the same function in both a subclass and its superclass, but with different code?

Subclass (Child or Derived Class)

  • Can access superclass (parent or base class)
    public & protected members
  • Can access own public, protected & private members

Can we have the same function in both a subclass and its superclass, but with different code? Yes!

Function Overriding

The function in the superclass is
overridden
by the function in the subclass.


Can we have it always use the subclass code, even if the current type is the superclass?

Function Overriding

The function in the superclass is
overridden
by the function in the subclass.


Can we have it always use the subclass code, even if the current type is the superclass? Use the virtual keyword!

Virtual Functions

Virtual functions can be
redefined
within subclasses.


Do we always have to implement the function in the superclass? No! Make the superclass an abstract class with pure virtual functions

void Student::whoAmI() {
  cout << "Student" << endl;
}
class Person{
  protected:
    int age;
  public:
    virtual void whoAmI() = 0;
};

class Student : public Person{
  public:
    void whoAmI();
};
int main(){
  Student student;
  Person person;
  person.whoAmI();
  student.whoAmI();
  return 0;
}
class Person{
  protected:
    int age;
  public:
    virtual void whoAmI()  = 0;
};

class Student : public Person{
  public:
    void whoAmI();
};

Review

  • Polymorphism - class hierarchies
  • protected keyword - self & subclass access only
  • Function Overriding - different code in superclass and subclass
  • virtual keyword - redefine functions in subclass
  • Abstract Class - virtual function with no definition
    • Cannot be instantiated!
