Create Impressive Presentations with Impress.js

Russ Feldhausen - NETC 2014

impress.js

What is impress.js?

  • A presentation framework based on CSS3 transforms
  • Uses Javascript to add functionality to HTML code
  • Inspired by Prezi
  • Requires functional knowledge of HTML5, CSS3 to use
  • Knowledge of Javascript needed to modify how it works

Why impress.js?

  • Prezi is cool, but creating presentations is labor intensive
  • PowerPoint is nice, but difficult to embed multimedia into
  • Pages is sweet, but not cross-platform
  • impress.js is HTML5, CSS and JS; cross-platform, and easy to work with
  • In addition, I'm a nerd, and its nerdy!

My experiences

  • 2 semesters of CS courses
  • 3 minor modifications to source code
    • Ability to define skipped slides
    • Escape key goes to overview
    • Youtube and Vimeo embeds
  • Wrote tool to create PDF notesheets
  • My presentations now flow very nicely

The Basics - CSS

.step {
  position:     relative;

  width:        1000px;
  padding:      40px;
  margin:       20px auto;

  box-sizing:   border-box;
  font-family:  'Open Sans', Arial, sans-serif;
  font-size:    48px;
  line-height:  1.5;

The Basics - CSS

.slide {
  display:        block;

  width:          1000px;
  height:         750px;
  padding:        40px 60px;

  background-color: white;
  border:         1px solid rgba(0, 0, 0, .3);
  border-radius:  10px;
  box-shadow:     0 2px 6px rgba(0, 0, 0, .1);
}

The Basics - Javascript

css(root, {
  transform: perspective( config.perspective / 
        targetScale ) + scale( targetScale ),
  transitionDuration: duration + "ms",
  transitionDelay: (zoomin ? delay : 0) + "ms"
});

css(canvas, {
  transform: rotate(target.rotate, true) + 
        translate(target.translate),
  transitionDuration: duration + "ms",
  transitionDelay: (zoomin ? 0 : delay) + "ms"
});

How it Works

  • Define slides within HTML <div> tags
  • Decorate slides with CSS
  • impress.js uses Javascript to add CSS transforms to slides
  • Key bindings in Javascript allow for movement
